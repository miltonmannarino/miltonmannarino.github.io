Poster gets relationships, masks, an effect stack, print ink and a font pack

Not browser-checked npm run check · green 100 files · +11,287 / −1,180 25 new modules 21 font families · 14 MB

One commit holds six days of Poster work (13 to 19 Oct). It adds eight new layer groups, a command palette, two look libraries, OpenType controls with a font inspector, in-browser object selection for pictures, and a bundled poster font pack. Engraving, sketch pens and picture analysis move into shared modules. The static suite and the production build pass. Nothing has been opened in a browser yet.

Relationships move the box before anything is drawn. Letter forms reshape the letters inside the text rasteriser. The effect stack runs any number of effects after the single slots. The source mask comes after the clip base, so layers clipped to a masked layer see the masked shape. Print ink is the last pass before the page blend, which now has a Pigment mode.

1What changed

Layer tab: relationships between layers

Layer › Relationships · every layer kind

  • Relationship select: No constraint, Avoid layer, Stay inside layer, Touch edge, Follow layer, Orbit layer, Connect to layer. Relative to lists every other layer. Gap and Strength apply to all modes. Follow adds Follow offset X / Y; Orbit adds Orbit radius and Orbit angle.
  • Avoid, Stay inside and Touch edge push the layer's box out of, inside, or against the target's nearest edge. Follow copies the target's position plus an offset in its rotated frame. Orbit circles it. Connect stretches and turns the layer so it spans from its own centre to the target.
  • Everything is display-only. The saved position never changes until Bake displayed position, which writes the shown transform in and sets the relationship back to No constraint. Picking, the selection box and the gizmo all use the displayed positions.
  • A deleted target makes the relationship inert. Chains and cycles of relationships terminate.

Layer tab: source masks

Layer › Mask › Mask from · every kind except adjustment

  • Mask from: No source mask, Gradient, Noise, Another layer, Painted mask. White shows the layer; Invert mask flips it. Mask level moves the edge and Mask softness widens it.
  • Gradient: Linear or Radial, Mask angle, Mask centre X / Y, Mask size. Noise: Mask size and Mask seed.
  • Another layer: Mask layer plus Read as Its shape or Its brightness. A hidden layer still works as a source.
  • Painted mask: Paint mask, Unpaint, Clear mask. The pencil paints it; [ and ] size the brush, Esc puts it down, B returns to the pencil. A drawing's refit carries the painted mask with it.

Layer tab: effect stack, and engraving on any layer

Layer › Effect stack · every inking kind

  • Add effect… offers Distort, Engrave, Sketch, Tone screen, Ink texture and Blur. Each becomes a numbered card with an on/off box and ↑ ↓ ✕ (Run earlier, Run later, Remove effect). The stack runs in card order after the layer's own single slots.
  • Engrave and Sketch now work on type, shapes and drawings, not only pictures. Their cards add Tone from (Layer colours or Flat level), Level, Line ink and Ground, so solid type can take even rulings. The picture's own Engrave and Sketch use the same shared shader code.
  • Stack settings are not keyframed and are skipped by Variation, like path effect parts.

Layer tab: print ink and the Pigment blend

Layer › Layer › Blend · Layer › Print ink · Finish › Print › Print look

  • Blend gains Pigment · overprint, last in the list. Ink behaves like transparent pigment on paper (single-constant Kubelka–Munk over seven spectral bands): cyan over yellow prints green, light ink on a dark page nearly vanishes, white ink adds nothing. Opacity is the amount of ink, not a cross-fade.
  • Print ink group: Ink spread wicks the ink along the paper's fibres, Pooling darkens the rim, Misregister slips and turns the plate, Ink starve thins it in blotches. Print seed appears once spread, misregister or starve is above zero.
  • Print look buttons Riso, Screen print, Offset and Clean set Pigment and these fields on the selected layers, or on every layer when nothing is selected. Clean zeroes them and puts the blend back to Normal.

Layer tab: brushes on paths and scribbles

Layer › Brush · drawing, path and scribble layers

  • The brush controls move out of Drawing into their own Brush group and now apply to paths and scribbles too. Brush: Solid ink, Paint bristles, Dry brush, Ink brush, and new Chalk, Marker and Calligraphy nib. With Bristles, Dryness, Sheen, Fill brush width, and for the nib Nib contrast and Nib angle.
  • Chalk grain sits in page units, so it stays on the paper when the layer moves. The nib is geometry: it scales the stroke width per point before painting. Text has no centreline and takes no brush.

Layer tab: grown type

Layer › Grow · text, glyph and path layers (currently at the bottom of the tab, after Transform)

  • Growth: Off, Coral, Maze, Spots, Worms (reaction–diffusion seeded inside the letters) or Lichen, Roots (growth automata seeded on the outline). Inside the letters, or Reach past them. Pattern size, Steps, Detail, Seed.
  • Colour: Layer ink, Growth colour, or Two-tone with Growth colour and Second colour. Original letters keeps the plain type underneath.
  • The simulation runs in a grid attached to the layer's box and is cached per layer. Panning, zooming, moving or recolouring never regrows it. Export waits for growth to settle.

Layer tab: organic paths and letter forms

Layer › Organic path · Layer › Warp › Organic outlines · Layer › Letter forms

  • Organic outlines (next to Letters to paths) turns type into an editable path with a broader refit. The Organic path group, shown for closed pen paths, has Sculpt / flourish amount, Simplify amount, and the buttons Simplify outline, Smooth points, Corner points, Swell, Pinch and Pull flourish. Show nodes with N, Mod-drag to pick points. These are real anchor edits with normal undo and export. The group currently sits at the bottom of the Layer tab, after Transform.
  • Letter forms reshape the set letters before anything else sees them. Form: Off, Slits, Slide, Fold, Facet, Modules, Flow, Terminals, Inlines; Style (Seed decides, or a named variant such as Slits · lenses, Flow · nouveau, Terminals · balls); Amount, Size, Scope (Each letter or Whole setting), Seed. A Second form slot repeats them. Random form, New seed and Clear forms drive both slots. Letters to paths and Warp letters see the formed letters. New type preset: Psychedelic flow.

Type: OpenType, a font inspector, text size and the font pack

Layer › OpenType · Layer › Text · every font picker

  • The OpenType group (Poster and Type mode) drives a face's variable axes and features: Width axis, Slant axis, Optical size, Other axes by tag, Capitals (small, all small, petite, all petite, unicase, titling), Ligatures, Numerals (lining, old-style, tabular, …) and OpenType features by tag. All of it is animatable.
  • This font's axes & features… opens an inspector that lists what the face has. For an installed font it reads the real file (Chrome, Local Font Access). For a shelf font it shows what the page asks Google Fonts for. Clicking an axis brings its control forward or writes it into Other axes; feature rows toggle into OpenType features.
  • A setting that uses an axis or a feature is drawn through an SVG rasteriser with the webfont embedded, so it lands a moment after the canvas draft and survives export.
  • Text size slider on text layers, in the active artboard's exported pixels. The box now follows the words: new words, another face or more tracking grow the box instead of shrinking the letters, and a corner drag sets the size. A multi-selection set to one value matches exactly.
  • Letter fonts (for example 3:Pinyon Script) sets single letters in faces of their own; Warp › Font scramble fills it with one contrasting letter per word.
  • Font pack: 21 OFL families bundled under public/fonts/poster, loaded with no Google request. The picker's single Built in section becomes three: Core (Archivo, Inter, Playfair Display, JetBrains Mono), Poster foundations (Anybody, Big Shoulders Display, Fraunces, Instrument Serif, League Gothic, Space Grotesk, Syne, Unbounded) and Mutant display (Climate Crisis, Kablammo, Handjet, Nabla, Bungee Shade, Bungee Outline, Rubik Glitch, Rubik Spray Paint, Rubik Wet Paint, Sixtyfour, Tilt Prism, Foldit, Wavefont). Their axes (YEAR, MORF, opsz, SOFT, WONK, …) are known to the inspector.

Pictures: select an object, the Effect library, analysis off the main thread

Layer › Mask › Select object · Layer › Image › Effect library

  • Select object runs Segment Anything in the browser. Click adds the part under the pointer, Alt-click or right-click takes it away, Backspace drops the last point, Enter cuts the picture to the object as an ordinary editable cut (Edit cut reshapes it), Shift+Enter or Selection to new layer lifts it onto a copy. The model is fetched on first use (transformers.js from jsDelivr, SlimSAM from the Hugging Face hub, about 14 MB on WASM or 20 to 40 MB on WebGPU) and cached by the browser.
  • Effect library heads the Image group: 28 whole-picture treatments on five shelves (Photographic, Print, Engraved & drawn, Cut & collage, Type & pixels), for example Faded film, Riso two-tone, Newsprint halftone, Copperplate engraving, Matisse cut-out, ASCII art, VHS tear. Every tile is the selected picture wearing that look. Shift-click compares without closing; Enter applies; the asset, fit, crop, transform, opacity and blend are never touched.
  • Silhouette, Snap to picture, Paper cut-out and Paper edges, Smooth shapes, Line art, Pixel sort and Dither are now built in a worker. Dragging them no longer freezes the page; the previous result shows until the new one lands. Exports, merges and the options grid build in place. Paper cut-out goes up to 8 colours with a new OKLab clustering.

3D: a library, studio light, surface textures and shared scenes

Layer › 3D · text, glyph and path layers

  • 3D library heads the group: 19 looks on the shelves Glass & gel, Metal, Soft solids, Stone clay & wood (Gummy gel, Brushed aluminium, Knurled steel, Inflated vinyl, Woven pillow, Pebbled leather, Ribbed rubber, Celadon crackle, Speckled enamel, Terrazzo slab, Raw concrete, Oak block, and the quick ones). The quick row is now Amber glass, Clear glass, Liquid chrome, Black metal, Studio chrome, Foam, Soft matte, Off.
  • Lighting: Classic · sky or Studio · soft light. Studio adds Self shadow, Shadow softness, Occlusion and Shadow on page: a soft key, real self-shadows, crevice occlusion, a contact shadow on a plane behind the solid, and softbox reflections that pick up the page. Materials add Soft matte and Foam / sponge.
  • Surface texture with 13 reliefs (Grain, Sponge pores, Pebbled leather, Hammered, Crackle glaze, Concrete, Brushed metal, Ribbed, Knurled, Woven fabric, Wood grain, Terrazzo, Paint speckle), plus Texture amount, Texture size, Texture angle and Chip colour. Worked in object space, so it stays on the surface as the solid turns.
  • Shared scene: spatial layers with the same scene name (up to six) are traced as one scene, so they intersect, hide and shadow each other. The scene draws at its top member's place in the stack and takes that member's light, camera and later passes.
  • Spatial 3D now draws a coarse draft while you drag, change a control or play the timeline, and sharpens about 200 ms after you stop. Exports and recordings never use the draft. A finished scene is reused while nothing it reads has changed.

Everywhere: the command palette

Toolbar ⌘K button, before Help · ⌘K / Ctrl+K

  • One search box over everything the current mode can do: Recent picks, Actions (toolbar and panel buttons, with key chips), Settings as Tab › Group (with each menu's options once two characters are typed), Fonts (each family drawn in its own face), Presets or Designs, Modes and Help topics.
  • Picking a setting switches to its tab, opens its group, scrolls to it, flashes a ring round it and focuses it. ↑ ↓ move, Enter runs, Esc closes. The Help shortcuts sheet gains the ⌘K row and a Select object block.

Under the hood

  • Marching squares moves out of the outliner into core/contours.js, shared by Image Trace, Letters to paths and the Facet form. Engrave and sketch GLSL move into one shared module, and the picture's CPU analysis into its own module plus an inline worker. The picture module shrinks by about 420 lines.
  • Three new check scripts join npm run check: letter forms (deterministic per seed, keeps letter ids, grows visible ink), organic path (simplify reduces anchors, the sculpt tools behave) and look presets (every look sets only valid in-range fields, never resets asset, fit, crop, transform, opacity or blend). Drift check declares the Poster-only field prefixes.
  • The commit message says Type Field and feedback repeaters were removed. The diff removes nothing for them: they were added and dropped again between commits, and only the PLAN.md log records it. No user-facing control was deleted.

2How to test

All of this is a manual pass in Poster mode. Open the app, add an artboard with a text layer and a picture, and keep the Layer tab open on the right.

Relationships

  1. Make two layers, A and B. Select A, go to Layer › Relationships, set Relationship to Avoid layer and Relative to B. Drag B over A.A slides away. A's own X and Y in the panel do not change.
  2. Switch A to Orbit layer and turn Orbit angle.A circles B at Orbit radius. Clicking A on the canvas picks it where it is shown.
  3. Press Bake displayed position.Toast "Baked 1 relationship into position". Relationship returns to No constraint and A stays where it was shown.
  4. Set A to Avoid layer again, then delete B.A drops back to its authored spot. No error in the console.

Source masks

  1. Select the picture, Layer › Mask, set Mask from to Gradient, drag Mask angle and Mask level.The picture fades across the box in that direction.
  2. Set Mask from to Painted mask, press Paint mask, drag on the page, resize with [ and ], press Esc, then Clear mask.Only the painted area shows, then the whole picture returns.
  3. Set Mask from to Another layer, choose the text layer, then hide the text layer.The picture shows only through the words.

Effect stack and print ink

  1. Select the text layer, Layer › Effect stack, Add effect… Engrave, set Tone from to Flat level.Even rulings across the solid type.
  2. Add Distort and press ↑ on its card so it runs before Engrave. Then untick the Engrave card.The rulings follow the distorted letters, then disappear when unticked while the card greys out.
  3. Draw a cyan and a yellow shape that overlap. Set both to Blend Pigment · overprint.The overlap prints green, not a cross-fade.
  4. Deselect everything, Finish › Print › Print look Riso, then Clean.Toast "Riso ink on the page"; every layer gains spread and misregister. Clean zeroes them and blends go back to Normal.

Brushes, grown type, organic paths, letter forms

  1. Draw a pen path with Stroke width above 0. Layer › Brush, set Brush to Chalk, then Calligraphy nib and turn Nib angle.Chalk grain stays on the paper when the path moves. The nib gives thick and thin along the angle.
  2. Select the text layer, scroll to the bottom of the Layer tab, Growth Coral. Move and recolour the layer. Export a PNG.The pattern fills in over a few frames, does not regrow on move, and the PNG is fully grown.
  3. On a text layer press Warp › Organic outlines, press N, Mod-drag round one point, press Pull flourish, then Simplify outline.A pointed flourish at that anchor, undo reverts it, and the simplify toast reads "n → m" points.
  4. On a text layer press Layer › Letter forms › Random form three times, then New seed, then Clear forms. Try Letters to paths with a form on.The toast names each form. The seed moves the shapes. Clear brings the font back. The paths carry the formed letters.

Type, fonts and the inspector

  1. Set the text layer to Fraunces, open Layer › OpenType, press This font's axes & features…, click SOFT.The menu lists opsz, SOFT and WONK. Other axes fills in and flashes, and the letters soften a moment after the draft.
  2. Open any font picker, pick Climate Crisis, set Other axes to YEAR 2050. Watch DevTools › Network.Three "· built in" sections in the picker. The letters erode. Fonts load from /fonts/poster/, not fonts.googleapis.com.
  3. Drag the new Text size slider, then type more words into the layer and drag a corner handle.The box grows for the new words at the same size; the corner drag changes the size.

Pictures and 3D

  1. Select the picture, Layer › Mask › Select object, click the subject, press Enter. Repeat with Shift+Enter.Toasts "Fetching the object model · …%" then "Select object (WebGPU or WASM) · click the object…". Enter leaves an editable cut; Shift+Enter puts it on a new layer.
  2. Layer › Image › Effect library. Shift-click two tiles, then click one. Drag Paper cut-out and Paper edges on a large photo.Tiles render as they scroll into view. Crop and transform are untouched after applying. The sliders stay smooth while the result catches up.
  3. Select the text layer, Layer › 3D › 3D library › Terrazzo slab. Set Lighting to Studio · soft light and raise Occlusion.A studio-lit solid with chips on every face. Shadow darkens the crevices and the page behind.
  4. Make two spatial text layers, give both Shared scene a, overlap them, then drag one.They intersect and shadow each other. A coarse draft shows while dragging and sharpens when you stop.
  5. Press ⌘K, type blend, pick the Layer › Layer entry. Reopen ⌘K.The Layer tab opens, the Blend control flashes and takes focus. The pick is listed under Recent.
