Airteam drone models now find their building

When Airteam delivers a drone survey, its 3D model (an OBJ file) reaches the right building in LumoCad without anyone uploading it. Projects that clearly match a building link themselves. The rest wait in a review list, where a person picks the building or corrects an automatic link.

What changed

Drone models arrive by themselves

A background process in the API asks Airteam for delivered projects every hour in production, and copies each matched project's OBJ into its building's Model files. The copy is needed because Airteam's download links expire after 24 hours. The bar shows where the 185 delivered projects with an OBJ landed in a read-only trial against production data.

  1. 29
    Exact address links itself. Exactly one building has the same postcode, street and house number, and its stored location is not more than 100 m away. Spelling doesn't matter: "An d. Kirche" equals "An Der Kirche" and "Goethepl." equals "Goetheplatz". The number does: no. 28 never links to no. 30.
  2. 47
    A strong building name links itself. The name holds the street and exact number, like "Musterhausen Parkstraße 1", and the city, postcode or a location within 100 m confirms it. Only one building may hold that name. A building that already holds a person's upload named <project id>.obj also links directly.
  3. 33
    Weaker clues become suggestions. Shared words and numbers, or a building within 100 m, put a building on the project's candidate list for a person to accept. So do several buildings or several projects sharing one address.
  4. 76
    Nothing to go on. The project waits in the review list until someone creates a matching building, which then links on the next run, or picks one by hand. 49 of the 76 were delivered in 2024 or earlier, or have no delivery date.

Trial numbers are evidence, not a guarantee. The trial used a slightly looser name test than the final one. Of 27 projects delivered in 2026, 22 linked themselves. Hidden, [delete] and test buildings are never linked or suggested.

The OBJ replaces the FastFusion link

FastFusion is Airteam's own 3D viewer, opened from a link stored on the building. In the trial, 26 of 51 stored links redirected to a 404 page, and the rest carry tokens that expire. Once a building has an OBJ, the link is ignored:

  • The Drone Model card in LumoCad opens Orbit with the top slice, never the FastFusion view.
  • The LumoCad FastFusion view and the building page's FastFusion tab show "Drone model available" with a way to open it.
  • Without an OBJ, the link works as it did.
  • If a building has several OBJs, such as a Revit export too, the Airteam file opens first.

Details that protect existing work

  • Saved alignment survives a redelivery. Alignment is saved per file, so a redelivered model updates the same file. Browsers now notice the newer file and download it again instead of showing their cached copy.
  • Nothing a person uploaded gets deleted. Reassigning removes only the file the sync created. The new building starts unaligned.
  • Rework is safe. Airteam can list no files during rework, and that removes nothing here.
  • The API key goes only to Airteam, never to download links, logs or responses.

How to test

In the real app, once released to production

Dev has no Airteam key on purpose, because it mostly holds dummy buildings, so production is the first real run. Restarting the worker starts the sync: the timer fires an hour later, or press Sync now. A run handles at most 40 projects, so importing all of them takes about five runs.

  1. As an admin, open Admin → Airteam and press Sync now.A message says "Sync queued. New models arrive within a few minutes." Reload after a few minutes: rows and counts appear.
  2. Open Auto-linked and pick a row saying "Linked by address". Open that building in LumoCad and choose Drone Model on the first screen.Orbit opens with the model and Top View shows its slice, without any upload. It sits near the scene centre and still needs aligning.
  3. Find a building that also has a FastFusion link. Open the FastFusion view in LumoCad, then the FastFusion tab on the building page.Both show "Drone model available" instead of the Airteam page. "Open drone model" opens Orbit; "Open in LumoCad" opens the building.
  4. On an auto-linked row, press Replace on a candidate or use Find a building.The row moves to Confirmed. The Airteam file leaves the old building's Model files and appears on the new one. Sync now changes nothing about it.
  5. Under Needs review, press Assign on one row and No building on another, then Restore that one under Dismissed.The first moves to Confirmed with a new file. The second leaves the list and comes back when restored.
  6. Log in without the admin role.No Airteam tab, and /admin/airteam doesn't open.

Automated checks

The method here was soft-fact: a spec of 37 examples and a set of rules signed off first, with tests that had to fail before the work existed and were locked after that. One locked test needed a typing-only fix, which was approved and signed off again.
