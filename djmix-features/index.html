How this page is kept

The djmix repo's CLAUDE.md makes it obligatory: a commit that adds or changes a feature also adds one object to the FEATURES array in this file (newest first), with what changed, the steps to test it and what is missing, then pushes this page. The CHECKS block records the last run of the automated checks.
