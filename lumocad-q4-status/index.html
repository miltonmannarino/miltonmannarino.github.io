    Stairs that span several floors

    Built, test
    BuiltWith 3 or more slabs ticked, you get one run per pair of slabs, each with its own turn. With only 2 ticked, one continuous run.     To tickU stair, tick the slabs of 4 storeys → 3 U runs, each turning on its own floor. Switch to bottom and top slab only → one run. Repeat with unequal storey heights.
