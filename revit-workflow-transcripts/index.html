Revit Production Workflow

Practical guide for architects

How to build the model in Revit.

A direct production workflow for turning point clouds and survey geometry into an aligned architectural model—without the meeting chatter.

01

Project setup

  1. Choose File → New → Project → Browse.
  2. Start from the latest approved LumoView template, or from the customer-specific template when one exists. Do not use Autodesk's default template.
  3. Load the RCS point clouds through the LumoCloud workflow: generate a token, paste it into the loader, and select all clouds needed for the building.
  4. Assign the matching point cloud to each storey view. Use a consistent sequence such as PC UG01, PC EG00, PC OG01, and PC OG02.
  5. Confirm that the ground-floor cloud includes the stair area. The stairs are the main vertical reference between storeys.
Rule: one view, one correctly assigned storey cloud. Fix this before modelling anything.
02

Levels and point-cloud alignment

Set vertical levels

  1. Open a ground-floor workspace where the section, floor, and stair clouds can be seen together.
  2. In section, draw a horizontal Reference Plane at the slab surface.
  3. Copy that reference plane to every visible slab and align each copy to its cloud.
  4. Annotate the planes relative to the project's 0.00 level.
  5. Update the Revit levels to match the reference planes, then verify them in section and 3D.

Align storeys horizontally

  1. Use stable building geometry: exterior walls and the stair core. Do not align storeys from furniture or lightweight interior features.
  2. Draw reference planes along reliable exterior and stair edges.
  3. Move each storey cloud until those edges align. Use arrow keys at a close zoom for fine adjustment.
  4. Verify at least two distant edges and both axes. A cloud that matches at only one point may still be rotated or offset.
03

Prepare the Airteam model

Use the OBJ as reference geometry

  1. Download the OBJ survey model and store it in the project's 3D CAD folder.
  2. Import it using metres as the unit.
  3. Isolate the imported object and export the isolated geometry as DWG.
  4. Import the DWG back into Revit and explode it once.
  5. After confirming the geometry was retained, remove the original DWG container.

Convert survey geometry into roof faces

  1. Convert the OBJ mesh to surfaces in Rhino or another suitable modelling tool.
  2. Export the surface model as SAT.
  3. In Revit, create an In-Place Mass and import the SAT inside it.
  4. Position the mass over the building and use its faces with Roof by Face.
04

Model the walls

Exterior and stair-core walls

  1. Determine exterior wall thickness from a visible opening or from the Airteam reference model.
  2. Select the matching wall type and draw to the point-cloud face.
  3. Use Wall Joins → Miter where the survey geometry requires a clean mitred corner.
  4. Set exterior walls to the next level with Top Offset = 0.
  5. Model stairwell walls early because they are a stable alignment reference across storeys.

Repeat walls across storeys

  1. Select the continuous walls and choose Copy to Clipboard → Paste Aligned to Selected Levels.
  2. Filter the selection so only walls are copied.
  3. After pasting, adjust every copy to the point cloud for its own storey. Never assume stacked floors are identical.

Interior and stacked walls

  • Measure partition thickness from the point cloud and use the corresponding wall type.
  • Attach full-height interior walls to the underside of the slab above.
  • Do not attach partial-height bathroom or toilet partitions to the slab above.
  • For stacked walls, create a new stacked type, insert the required basic wall types, align their exterior faces, set the lower segment's fixed height, and make the upper segment Variable.
05

Place doors and windows

Windows

  1. Read width and horizontal position from the floor-plan cloud.
  2. Read sill height and overall window height from the section cloud.
  3. Place the window in the correct host wall and check which side of the family faces the interior.
  4. Select the family configuration that matches the survey: rows, columns, and panel arrangement.

Doors

  1. Read width and position from the floor-plan cloud, and height from the section cloud.
  2. Confirm the host wall, swing direction, and opening direction.
  3. Use a family that matches the observed configuration: single, double, side panel, or transom.
Check in plan and elevation. Correct dimensions are not enough if the family is flipped, hosted incorrectly, or has the wrong panel layout.
06

Choose and build the roof

MethodUse it whenWatch for
Roof by FootprintThe roof is planar and its slopes are known.Limited control where unequal slopes meet or steep edges terminate.
Roof by FaceThe SAT survey surfaces are reliable and the geometry is complex.Face joins may need cleanup and testing.
Model In-Place: Sweep / RevolveA special roof needs precise profile or edge control.More manual work and less standard behaviour.
Modify Sub ElementsThe roof must remain native or host roof openings.Warped faces can produce inconsistent visible thickness.

A. Roof by Face

  1. Convert the OBJ mesh to surfaces and export them as SAT.
  2. Create an In-Place Mass, import the SAT, and position it over the building.
  3. Choose Architecture → Roof → Roof by Face and select the required mass faces.
  4. Hide the source mass and inspect ridges, valleys, and transitions.

B. Model-in-place roof

  1. Create a model-in-place element in the Roofs category.
  2. For a sweep, sketch the path and then the section profile, including thickness and any projecting or sloped parts.
  3. Inspect the result in section. Keep the Airteam model visible while adjusting the path and profile.
  4. Join separate roof pieces when the form requires multiple sweeps.
  5. For a revolve, define the rotation axis and profile, create the form, and position it against the main roof.

C. Native roof with editable points and edges

  1. Create a basic footprint at the correct level.
  2. Use Modify Sub Elements, Split Lines, and Add Point to create the surveyed form.
  3. Set edge and point elevations from the reference geometry.
  4. Verify the resulting thickness and confirm that roof-hosted openings still work.
Do not choose the method by habit. Choose it from the geometry, required editability, and whether the roof must host native openings.
07

Build curtain walls

  1. Use a predefined curtain-wall type for a regular generated layout. Use an empty type when the grid must be built manually.
  2. For generated grids, set the type rule to fixed distance or maximum spacing, then inspect the remainder at the ends.
  3. Generated panels are pinned. Unpin a panel before replacing it.
  4. Use curtain-wall-hosted doors and windows; standard wall-hosted families will not behave correctly.
  5. Use Curtain Grid to add grid lines and Add/Remove Segments to control partial grids.
  6. Unpin mullions before changing their profile or type.
  7. After changing host dimensions or type rules, check the entire wall again. Manual overrides can become inconsistent after regeneration.
08

Final model checks

  • Every view shows the correct storey cloud.
  • Levels match the stair and section clouds.
  • Exterior walls and the stair core align across storeys.
  • Exterior walls terminate at the next level with zero top offset.
  • Required wall corners use the correct join condition.
  • Walls copied between levels were corrected to each storey's cloud.
  • Full-height partitions stop at the slab underside.
  • Partial-height partitions remain partial height.
  • Stacked walls have correct thicknesses and the intended variable segment.
  • Doors and windows have the correct position, size, host, direction, and configuration.
  • Roof ridges, valleys, and perimeter edges match the reference geometry.
  • Roof thickness remains acceptable on warped faces.
  • Roof-hosted openings still work.
  • Curtain grids, panels, and mullions remain consistent after resizing.
09

Command reference

  • Reference Plane — establish slab elevations and stable alignment axes.
  • Paste Aligned to Selected Levels — repeat walls across storeys.
  • Attach Top/Base — terminate full-height partitions at the slab.
  • Wall Joins → Miter — correct wall corner geometry.
  • In-Place Mass + Roof by Face — turn imported SAT surfaces into roof elements.
  • Model In-Place → Sweep — create profile-driven roof forms.
  • Model In-Place → Revolve — create rotational roof forms.
  • Modify Sub Elements — edit native roof points, ridges, and edges.
  • Curtain Grid — add curtain-wall divisions.
  • Add/Remove Segments — control partial curtain grids.
