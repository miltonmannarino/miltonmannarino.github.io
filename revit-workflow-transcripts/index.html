0.0 Random Helpful Revit Things

Tidy Tabs Revit

File: Tidy_Tabs_Revit.mp4 Duration: 00:29

I have so many tabs open in this one project, but I know I have a second project open. How do I get to my other project without manually closing all of these? There is a button, Close Inactive Views, which closes all the tabs you have open down to one tab per project that is currently open in Revit. It is that easy and very helpful.

The page also documents Revit's Temporary Hide/Isolate tool, represented by the glasses icon. When active, the view gets a blue border. Open the tool again and choose Reset Temporary Hide/Isolate to restore the hidden elements.

1. Premodelling

1.1 Create a new project using the Lumoview template

File: Bildschirmaufnahme_2026-03-27_um_15.31.12.mov Duration: 01:17

Before I start modelling, I create a new project using the LumoView Revit template. I choose New > Model, but we do not use Revit's default templates. Choose Browse, then go to the Google Drive shared folder, the Customer Success/Revit standards area, LumoView, and the template files. Use the latest general LumoView template, not the one marked “do not use.” There may also be customer-specific templates here—for example, Combistro or Ecoplan—so choose the correct one for the project, open it, and press OK. The project is ready.

1.2 Load point clouds — part 1

File: Bildschirmaufnahme_2026-03-27_um_16.15.22.mov Duration: 01:46

To load the point clouds, choose Load RCS. RCS is the point-cloud file type. Revit asks for a login token to connect to LumoCloud. Generate the token, confirm the dialog, copy the token to the clipboard, paste it into Revit, and press OK. In the selection dialog, check Select all to load all of the available point clouds.

The recording is mostly UI interaction; several spoken connector words around the token dialog are inaudible.

1.2 Load point clouds — part 2

File: Bildschirmaufnahme_2026-03-27_um_16.21.46.mov Duration: 02:32

When point-cloud loading is complete, a window appears. Press OK. The point clouds are now in the file, but they are not visible yet. For the basement, change the base-level underlay/range to PC UG01; the basement point cloud appears. For the ground floor, choose PC EG00. The ground-floor data also contains the stairs, which will be important both for creating the stairs and for determining the floor heights later. Continue for the other storeys: PC OG01, PC OG02, and PC OG03. Then go through the workspaces/floor plans, beginning with the basement (UG), and set the corresponding point cloud as the underlay for each floor. Repeat this for all other floors.

1.5 Import Airteam model as a DWG file

File: Bildschirmaufnahme_2026-03-30_um_12.25.07.mov Duration: 02:29

First go to the Airteam Cloud website and find the project whose Airteam model you need. Open the project, scroll to the 3D model, and download the OBJ file. Copy it from Downloads into the project's 3D CAD model folder. Drag the OBJ into the Revit file and choose metres as the units. Isolate the imported 3D model, then export it as DWG into the folder containing the Revit project. Leave Temporary Hide/Isolate mode active while exporting. Drag the resulting DWG back into Revit, explode it once, and delete the original imported DWG container. The converted geometry remains available in the project.

1.3 Determine storey heights using stair point clouds

File: Bildschirmaufnahme_2026-03-31_um_15.36.24.mov Duration: 04:21

To determine the storey heights, navigate to the floor plans. In the EG00 ground-floor workspace you can find the section point cloud, the floor-plan point cloud, and the staircase point cloud. Zoom into the staircase and use the Reference Plane tool. Draw a horizontal reference plane and align it to the point cloud, then copy it to each slab. This also lets us determine the slab heights. First position the planes and then adjust them accurately against the point clouds for each floor. [The presenter zooms into each slab and fine-tunes several planes.] Annotate the heights, using the ground floor as 0.00. Copy the annotation to the other floors and write down the measured heights. The spoken values are partially unclear; values resembling -2.78, 3.30, 7.57, and 11.66 are entered. Finally, open the 3D view and correct the Revit level elevations and resulting storey heights to match those measurements.

1.4 Align point clouds from different floors with reference planes

File: Bildschirmaufnahme_2026-04-01_um_12.01.35.mov Duration: 04:46

To align the point clouds from one floor to another, identify reliable building features: the external walls and the staircase. Here we can see the edges of the outside walls and the staircase. Use Reference Plane to draw lines on the edges of the outside walls, and then adjust the point clouds against those planes. Do this for each relevant wall and copy the reference planes as needed. Add reference planes around the stair. Move from the first floor down to the ground floor; the point clouds are visibly not in the same position. Move the point cloud into place. The arrow keys can be used for small movements. Zoom in to make more precise adjustments. [A long quiet section follows while the alignment is refined.] The point cloud should now be in the correct position relative to the other floors.

2. 3D postprocessing

2.3 External walls — exterior walls

File: Exterior_Walls.mp4 Duration: 02:01

After setting up the point clouds, it is useful to create reference planes or lines so all point clouds can be aligned to the same references. In this project there is also an Airteam model. If there is no Airteam model, use features such as a balcony door or windows to determine the wall thickness. Choose an exterior-wall type and use the measured thickness—35 centimetres in this example. Close the corner and move the wall into the correct position. Where correct wall joins matter, open Wall Joins, click the corner, and choose Miter. Exterior walls should extend to the top of the next floor. A floor slab normally occupies some of the storey above, but the exterior wall continues upward. Select the exterior walls, set Top Constraint to the next level, and set Top Offset to zero.

2.3 External walls — stacked walls

File: Stacked_Walls.mp4 Duration: 02:39

A wall may need different materials or thicknesses above and below a break—for example, a below-ground part and an above-ground part, or concrete below with another construction above. Select a wall and create a Stacked Wall type. Duplicate a type, give it a name, and turn on the preview. Insert as many component walls as required. In this example the lower wall is 12 centimetres thick and the upper wall is 25 centimetres thick. Align both components to the exterior face. Rather than fixing both component heights, make one component Variable. Set the lower component to a fixed height of two metres and let the 25-centimetre component fill the remaining height of the stacked wall.

2.2 Stairs / 2.4 Walls of the stairwell

File: Wall_Stairs.mp4 Duration: 02:30 Note: the identical file is embedded on both child pages.

After setting up the outside walls, I usually continue with the stairwell. In many buildings the exterior walls and stairwell walls continue from the basement to the top. That is not always the case, but it is true for this building. Measure the stairwell wall—25 centimetres here—and use an interior-wall type. Starting with these walls means that, once they are complete, they can be copied to every storey. On each higher floor, adjust the point cloud to those walls. The walls become the reference for the next floor and remain aligned through the building. Adjust individual wall thicknesses where needed. This example has three entrances with three stairways, but the recording models only one. Select the walls, use the filter to keep only walls, and choose Copy to Clipboard > Paste Aligned to Selected Levels. Paste them to the first, second, and third floors. Revit now has the building exterior together with the stairwell walls on those levels.

2.1 Roof modelling — roof via surfaces

File: Roof_via_Surfaces.mp4 Duration: 05:45

The Notion page describes this as a work-in-progress method: convert the mesh-based Airteam OBJ into a surface model, export SAT, import it into a Revit mass, and create a roof with Roof by Face.

This video shows how to model the roof directly from the surfaces of the Airteam model. The main roof is inclined, and its front and back edges are not parallel. An extrusion or simple footprint would average the geometry and would not align perfectly. There are also additional complex roof parts. The Airteam model begins as a mesh. Convert it into surfaces in Rhino and export it as an SAT file, which works well for selecting faces in Revit. In Revit, open Massing & Site, create an In-Place Mass, and import the SAT inside that mass. Position the imported model over the building. This demonstration uses an approximate placement. With the imported model inside the mass, isolate it and choose Architecture > Roof > Roof by Face. Select the required faces and create the roof. Hide the Airteam mass. In less than five minutes, Revit has produced a roof with a complex form. The method is not mature yet and the joins around some complex faces still need testing, but it is a very fast way to obtain the overall roof shape. Whether to use every face or only the main faces depends on the project.

2.1 Roof modelling — regular roof versus model-in-place

File: Roof_demo_Lidiceplatz.mp4 Duration: 19:22

This demonstration compares Revit's regular roof tool with a model-in-place roof. Each is suitable for different cases. The example roof has one very steep slope of about 69 degrees, another slope of about three degrees, and a custom curved or special form. Start with Roof by Footprint. Remove slope from the two side edges, set the steep and shallow angles, and place the roof on OG04. The result does not match the source roof because angle-based footprint construction does not let us decide exactly where the two slopes meet. Split the roof into two pieces, model each piece independently, and join them. Adjust the footprints and align the edges. This gives a closer approximation. A drawback of the regular roof tool appears on a steep 69-degree slope: the roof termination and edge thickness are difficult to control. If the intended construction is 28 centimetres thick, the end does not necessarily terminate as a clean, consistent 28-centimetre edge. The presenter's preferred alternative is an in-place component in the Roofs category. Use a Sweep: sketch the path, then draw the roof's section profile. The profile follows the path and produces cleaner edges. Include the small projecting, shallow-sloped part in the profile. Set the material and inspect the result in section. Keep the Airteam model visible as a reference. Edit the sweep profile until it follows the source geometry, adjust the footprints, and join the pieces. The model-in-place result is thinner and joins more cleanly than the first footprint result. It is controlled by a path and profile rather than only by slope angles, so the form can be deepened or reshaped directly. Model the roof's distinctive curved feature with Revolve. Define a vertical axis, sketch an approximate profile of the feature, finish the revolve, and move it into position against the other roof geometry. The demonstration is approximate; production work still needs accurate proportions, measurements, profiles, and placement.

2.1 Roof modelling — roof via points and edges

File: Roof_via_edges.mp4 Duration: 08:52

This video models the roof with points and edges while retaining a regular Revit roof. Load the Airteam model, place the roof at OG04, choose Roof by Footprint, and sketch an approximate outline. This is a demonstration, so the geometry is deliberately not fully detailed. Select the finished roof and use Modify Sub Elements. The relevant tools are Add Point, Split Line, and Pick Supports. Add split lines that correspond to the visible ridges and breaks in the Airteam roof. One ridge is inclined relative to another; where appropriate, draw it parallel to the front edge rather than the back edge. Add the remaining visible edges. Adjust the elevation of the new edges and points until the roof follows the Airteam model. [The presenter spends several minutes moving the sub-elements while mostly silent.] For a more complex form, add and move individual points. Revit exposes the height of each point, which allows local control over the surface. The result remains a real Revit roof rather than generic geometry, so its thickness can be changed and it can host roof windows and roof openings. The disadvantage is complexity: modifying sub-elements can make the effective roof thickness vary from face to face instead of remaining uniform. This method therefore preserves native roof behaviour but may produce inconsistent construction thickness on a highly warped form.

2.6 Internal walls

File: Interior_Walls.mp4 Duration: 02:48

After the exterior and stairwell walls are in place, continue with the interior walls that define the room arrangement. In this example the walls are clearly visible in the point cloud, so the work is mainly measuring their thicknesses and drawing them. If apartments repeat on multiple floors, copy the walls to those floors instead of redrawing them, then correct their positions against each floor's point cloud. This is building-dependent and is not always the best approach. Interior walls should normally stop at the underside of the slab above rather than overlap it. Select the walls and attach their tops to the slab. Revit may warn that some selected elements do not touch the target; those are exterior walls and can be left unchanged. After attachment, the interior walls end at the slab. Do not include partial-height walls—such as 1.20- or 1.50-metre bathroom walls—in this operation unless their height is corrected afterwards.

Curtain Walls

File: Curtain_Walls.mp4 Duration: 05:38

A curtain wall is another Revit wall type. Revit provides predefined and empty variants. I usually start from a predefined type and adjust it. Draw it like a normal wall, then select it and edit its type. The example begins with a vertical-grid layout using a fixed distance of 1.50 metres. Change the layout rule—for example, to a maximum spacing of 1.15 metres—and Revit redistributes the grids. Panels can also be changed. Most generated curtain-wall elements are pinned by default, so unpin a panel before replacing it with a solid panel or another type. Curtain walls can host curtain-wall-specific doors and windows. Ordinary hosted door families will not work unless they are designed for curtain walls. A basic wall can also be embedded into a curtain wall. Use Curtain Grid to add grid lines. To keep only part of a line, select it and use Add/Remove Segments. Add or remove mullions as required. Generated mullions are pinned; unpin one before changing its type—for example, from a 30-millimetre square mullion to a round mullion. Curtain walls are flexible but easy to make inconsistent. If the grid began with a fixed 1.50-metre spacing, was changed to a 1.15-metre maximum, and then received manually added mullions, later resizing the wall may mix up the manually and automatically generated elements. Recheck and correct the layout after dimension changes. The empty curtain-wall type starts without generated grids or mullions. Add reference-driven curtain grids manually, split the wall where required, and place mullions on the desired grid segments. Each mullion can then be unpinned and changed independently.

Workflow knowledge distilled from the recordings

  • Establish shared references before modelling: levels come from stair/section point clouds, while cross-storey XY alignment comes from exterior-wall edges and stair cores.
  • Use the correct LumoView or customer-specific template before importing any project data.
  • Load all RCS clouds through the LumoCloud token flow, then expose the corresponding PC_* cloud in each storey's view/underlay.
  • Model elements that repeat vertically—exterior walls and stair cores—early, copy them to selected levels, and use them as alignment references for the remaining storeys.
  • Exterior walls reach the next level; ordinary full-height interior walls attach to the underside of the slab above. Treat partial-height walls separately.
  • Use stacked walls where construction or thickness changes vertically. Keep one component variable so it fills the remaining storey height.
  • Airteam OBJ geometry is used in two ways: as a visual reference after conversion through DWG, or as selectable surfaces after mesh-to-surface conversion and SAT import into a Revit mass.
  • For complex roofs, choose between three trade-offs: Roof by Face is fastest from good surface input; a model-in-place sweep/revolve gives strong profile control; a sub-element-edited native roof preserves roof hosting but can distort thickness.
  • Curtain-wall grids, panels, and mullions mix generated and manually overridden elements. Recheck them whenever the host dimensions or layout rule changes.
