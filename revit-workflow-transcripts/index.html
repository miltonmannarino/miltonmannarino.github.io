01

Useful workspace controls

Close excess view tabs

When many views are open—or more than one Revit project is open—use Close Inactive Views. Revit closes the extra tabs and leaves one active view for each open project. This tidies the workspace without closing the projects themselves.

Hide or isolate geometry temporarily

  1. Select Temporary Hide/Isolate, represented by the glasses icon.
  2. Hide an obstructing object or isolate the geometry needed for the current operation.
  3. A blue border around the view means Temporary Hide/Isolate is still active.
  4. To restore the full view, open the glasses menu again and choose Reset Temporary Hide/Isolate.
Important during exports: an export made while Temporary Hide/Isolate is active can be limited to the visible isolated geometry. Always notice the blue view border.
02

Create the project and load the point clouds

Start from the correct template

  1. Choose New Model, then Browse.
  2. Open the shared Revit standards area and locate the LumoView template files.
  3. Use the latest approved general LumoView template. Do not use Autodesk's default templates and do not choose a file marked “do not use.”
  4. If the project has a customer-specific template, use it instead of the general template.
  5. Open the selected template and confirm with OK.

Connect to LumoCloud and load RCS files

  1. Choose Load RCS. RCS is the point-cloud file type used by the workflow.
  2. When Revit requests the LumoCloud login token, generate the token and confirm the dialog.
  3. Copy the generated token, paste it into Revit, and press OK.
  4. In the point-cloud selection dialog, choose Select all to bring in every available storey cloud.

Assign one point cloud to each floor-plan workspace

  1. Begin with the basement view and assign PC UG01.
  2. Assign PC EG00 to the ground-floor view. Confirm that this cloud also contains the stair information needed later for levels and stair modelling.
  3. Continue storey by storey with PC OG01, PC OG02, PC OG03, and any further clouds supplied for the project.
  4. Check every floor-plan workspace or underlay. The cloud name and storey must correspond.
Stop and fix mismatches now. Levels, wall placement, openings, and copying between storeys all depend on the correct cloud being visible in each view.
03

Determine levels and align the storeys

Determine storey heights from the stair and section clouds

  1. Open the ground-floor workspace. Make sure the floor-plan cloud, section cloud, and stair cloud can be inspected together.
  2. Zoom into the staircase, where successive slabs can be read in a common vertical reference.
  3. Use Reference Plane to draw a horizontal plane on the first slab surface.
  4. Copy the reference plane to every visible slab. Zoom closely and align each copy precisely with the corresponding cloud surface.
  5. Use the ground floor as 0.00 and read the relative elevation of each reference plane.
  6. Update the Revit level elevations and resulting storey heights so they match those measured planes.
  7. Review the levels in section and 3D before continuing.

The demonstrated building produced levels at approximately -2.78, 0.00, +3.30, +7.57, and +11.66. These values illustrate the measurement method only; use the values from the current building's point clouds.

Align point clouds in plan

  1. Choose reliable geometry that continues between floors: exterior-wall faces and the stair core are the main references.
  2. Do not use furniture, equipment, or lightweight interior features as the main alignment reference.
  3. Draw reference planes on the visible exterior-wall edges. Copy or extend the planes where several edges are needed.
  4. Add reference planes around the stair core.
  5. Move from one storey to the next and compare the clouds. If the next cloud is offset, select it and move it against the shared reference planes.
  6. Use the arrow keys for small movements. Zoom in before the final adjustment.
  7. Check more than one distant wall edge, the stair core, and both plan axes. A cloud that matches at one point can still be rotated or offset elsewhere.
Sequence: establish vertical levels first, then align the storey clouds in XY, then start architectural modelling.
04

Prepare and use the Airteam model

Convert the OBJ into editable Revit reference geometry

  1. Open the correct project in Airteam Cloud, find its 3D model, and download the OBJ file.
  2. Move the downloaded OBJ into the project's 3D CAD model folder so the source geometry stays with the Revit project.
  3. Bring the OBJ into the Revit file and set the import unit to metres.
  4. Use Temporary Hide/Isolate to isolate the imported 3D model.
  5. While the isolated view is active, export the visible geometry as a DWG into the folder containing the Revit project.
  6. Import or drag the resulting DWG back into Revit.
  7. Explode the imported DWG once.
  8. Confirm that the converted geometry remains in the project, then delete the original imported DWG container.
  9. Reset Temporary Hide/Isolate when the conversion is complete.

Use the model in two different ways

  • Visual reference: use the DWG-converted geometry to compare the Revit model with the surveyed building.
  • Selectable roof surfaces: convert the mesh-based OBJ into a surface model outside Revit, export SAT, and import that SAT into an In-Place Mass. The detailed roof-by-face procedure is below.
05

Model exterior, stair-core, stacked, and interior walls

Establish wall references and thicknesses

  1. Keep the aligned point clouds and Airteam model available as references.
  2. If no Airteam model exists, use visible features such as balcony doors or windows to infer the exterior wall thickness.
  3. Create reference planes or lines so the clouds and wall faces are checked against the same geometry.
  4. Select or create the wall type with the measured thickness. The exterior wall in the demonstration was 35 cm; do not reuse this dimension unless the current survey supports it.
  5. Draw and move the exterior walls so the correct wall face follows the point cloud.

Join and constrain exterior walls

  1. Close the wall corners.
  2. Where the corner must form a clean mitre, choose Wall Joins, select the corner, and set the join to Miter.
  3. Select the exterior walls and set Top Constraint to the next level.
  4. Set Top Offset to 0.

Exterior walls usually continue to the next level even though the floor slab occupies part of the storey above. Do not stop them at the slab underside by default.

Model the stair-core walls early

  1. After the exterior shell, model the stairwell walls. In many buildings the exterior and stair-core walls continue from basement to top, but verify that this is true for the current building.
  2. Measure the stairwell wall thickness from the cloud and use the matching interior-wall type. The demonstration used 25 cm.
  3. Use these walls as a stable cross-storey reference.

Copy continuous walls between storeys

  1. Select the exterior and stair-core walls that genuinely continue through the building.
  2. Use the selection filter and keep only Walls.
  3. Choose Copy to Clipboard → Paste Aligned to Selected Levels.
  4. Select the required upper storeys and paste.
  5. On every pasted level, compare the walls with that storey's point cloud. Move walls and change individual thicknesses where the survey differs.
Copying is a starting point, not proof that the floors are identical. Only use it where the building repeats, and always correct the result against the destination cloud.

Create a stacked wall when construction changes vertically

  1. Select a wall and change it to a Stacked Wall type.
  2. Duplicate the type, give it a project-specific name, and turn on the preview.
  3. Insert as many basic-wall components as required.
  4. Align the component walls by their exterior faces.
  5. Set the known lower component to a fixed height and mark the component that should fill the remaining storey height as Variable.

In the demonstration, the lower component was 12 cm thick and fixed at 2.00 m high; the upper component was 25 cm thick and variable. These are example inputs, not default values.

Model and constrain interior walls

  1. After the exterior and stair-core walls are established, use the point cloud to read the apartment or room layout.
  2. Measure each partition thickness and draw it with the corresponding wall type.
  3. If apartment layouts repeat, copy the interior walls to the relevant floors and then correct them against each destination cloud. This is building-dependent and is not always the best method.
  4. For ordinary full-height interior walls, use Attach Top/Base and attach the wall tops to the underside of the slab above.
  5. If Revit warns that some selected elements do not touch the target, review the selection. Exterior walls can remain unchanged because they follow a different top-constraint rule.
  6. Exclude partial-height walls—such as 1.20 m or 1.50 m bathroom partitions—from the attach operation. If they were included accidentally, restore their intended height.
06

Place and configure windows and doors

Windows

  1. Use the floor-plan point cloud to determine the window width and horizontal position.
  2. Use the section point cloud to determine the sill height and total window height.
  3. Place the window in the correct host wall.
  4. Check the family direction. Confirm that the interior sill is on the inside and flip the family if required.
  5. Create or select the required type and match its rows, columns, and panel configuration to the surveyed window.
  6. Verify the result in plan, section, and elevation.

Doors

  1. Use the floor-plan point cloud to determine door width and position.
  2. Use the section point cloud to determine the door height.
  3. Place the door in the correct host wall.
  4. Check the direction of the opening panel and the swing direction; flip it where necessary.
  5. Select the family configuration visible in the survey: single leaf, double leaf, side panel, transom, or another matching arrangement.
  6. Verify the result in plan, section, and elevation.
Dimensions alone are insufficient. A correctly sized opening can still be wrong because of its host, interior/exterior direction, swing, panel count, or family configuration.
07

Select and execute the appropriate roof method

MethodBest useMain advantageMain limitation
Roof by FootprintSimple planar roofs with known slopes.Fast, standard native roof behaviour.Poorer control where unequal slopes meet or a steep edge must terminate cleanly.
Roof by FaceComplex roofs when accurate SAT surfaces can be produced.Very fast conversion of surveyed faces into a roof.Complex face joins may need testing and cleanup.
Model In-Place: Sweep / RevolveSpecial shapes needing direct path, profile, or curved-feature control.Clean, precise control of form and edge profile.More manual and less standard than a native footprint roof.
Modify Sub ElementsComplex geometry that must remain a native Revit roof and host roof elements.Retains native thickness settings and roof hosting.Highly warped faces can show inconsistent effective thickness.

Method A: Roof by Face from Airteam surfaces

  1. Use this method when the Airteam roof has non-parallel edges, several complex parts, or geometry a simple extrusion or footprint would average incorrectly.
  2. Convert the mesh-based Airteam OBJ into a surface-based model in Rhino or another suitable tool.
  3. Export the surface model as SAT.
  4. In Revit, open Massing & Site and create an In-Place Mass.
  5. Import the SAT inside the mass and finish the mass.
  6. Position the imported geometry accurately over the building.
  7. Isolate the imported mass if needed.
  8. Choose Architecture → Roof → Roof by Face, select the required faces, and create the roof.
  9. Decide whether the project needs every surveyed face or only the principal roof faces.
  10. Hide the Airteam mass and inspect ridges, valleys, transitions, and joins.
This method is fast but must be checked. The source describes it as a developing workflow; joins around complex faces still require project-specific testing.

Method B: Standard Roof by Footprint

  1. Create Roof by Footprint at the correct level.
  2. Sketch the outline and remove Defines Slope from edges that should not generate a slope.
  3. Enter the measured slope for each sloping edge.
  4. If two very different slopes do not meet correctly in one footprint, split the roof into separate pieces.
  5. Model the pieces independently, adjust their footprints, align their edges, and join them.
  6. Inspect steep terminations in section. A standard roof may not produce a clean edge with the intended construction thickness.

The demonstration compared a slope of about 69° with one of about 3° and targeted a 28 cm construction thickness. These values expose the limitation; they are not defaults.

Method C: Model-in-place sweep

  1. Create a model-in-place component in the Roofs category.
  2. Choose Sweep and sketch the path.
  3. Draw the roof section as the sweep profile. Include the full thickness and any small projecting or shallow-sloped portion.
  4. Assign the required material.
  5. Finish the sweep and inspect it in section.
  6. Keep the Airteam model visible while editing the path and profile so the new form follows the surveyed geometry.
  7. Deepen or reshape the profile directly where a slope-only roof cannot reproduce the construction.
  8. Adjust the adjacent roof footprints or pieces and join the geometry cleanly.

Method D: Model-in-place revolve

  1. Use a revolve for a distinctive curved or rotational roof feature.
  2. Define the rotation axis.
  3. Sketch the feature's section profile.
  4. Finish the revolve and move it into its correct position against the main roof geometry.
  5. Replace approximate demonstration geometry with measured proportions, profile, and placement in production.

Method E: Native roof controlled by points and edges

  1. Load and position the Airteam model as a visible reference.
  2. Create a basic Roof by Footprint at the correct level and sketch the approximate perimeter.
  3. Select the finished roof and choose Modify Sub Elements.
  4. Add Split Lines along the visible ridges and breaks in the Airteam roof.
  5. When a ridge is inclined relative to another edge, reproduce the visible survey geometry rather than forcing an assumed parallel relationship.
  6. Add the remaining visible edges, then edit their elevations until the roof follows the source model.
  7. Use Add Point for local control of more complex areas and set each point's height.
  8. Inspect the finished surfaces and thickness from several views.
  9. Confirm that the native roof still hosts roof windows and openings correctly.

This method keeps a real Revit roof: its type thickness can still be changed and native hosted elements remain available. Its trade-off is that sub-element deformation can make the effective construction thickness vary from face to face.

08

Build and control curtain walls

Start with the correct type

  1. Draw the curtain wall like a normal wall, then select it and edit its type.
  2. Use a predefined type when Revit should generate a regular grid and mullions.
  3. Use an empty curtain-wall type when the grid must be constructed manually from reference-driven divisions.

Control generated grids

  1. Set the vertical or horizontal layout rule. For example, use Fixed Distance when the module is exact or Maximum Spacing when Revit should redistribute the divisions.
  2. Inspect the full wall and the remainder at both ends after changing the rule.
  3. The demonstration changed a fixed 1.50 m layout to a maximum spacing of 1.15 m; these values illustrate how redistribution works.

Panels, doors, windows, grids, and mullions

  1. Generated curtain-wall panels are normally pinned. Unpin a panel before replacing it with a solid panel or another panel type.
  2. Use curtain-wall-specific door and window families. Ordinary wall-hosted families do not work unless they are designed for curtain walls.
  3. A basic wall can also be embedded as a curtain-wall panel where required.
  4. Use Curtain Grid to add grid lines.
  5. To keep only part of a grid line, select it and use Add/Remove Segments.
  6. Add or remove mullions on the required grid segments.
  7. Generated mullions are pinned. Unpin a mullion before changing its type or profile—for example, from a 30 mm square mullion to a round mullion.

Build a manual curtain wall

  1. Start with an empty type that has no automatically generated grids or mullions.
  2. Add the curtain grids manually from the project references.
  3. Split the grid or wall where required.
  4. Place mullions only on the desired segments.
  5. Unpin and change individual mullions where their types differ.
Recheck after every resize or rule change. A wall that combines automatic layout rules with manually added grids, panels, or mullions can become inconsistent when its dimensions change.
09

Final model checks

  • The project uses the current approved general or customer-specific template.
  • Every floor-plan workspace shows the point cloud for the correct storey.
  • The ground-floor workspace includes the stair information needed for level measurement.
  • Revit levels match the stair and section clouds.
  • Every storey cloud aligns to several exterior-wall references and the stair core in both axes.
  • Temporary Hide/Isolate has been reset unless it is intentionally active.
  • Imported Airteam geometry uses metres and is positioned correctly.
  • Exterior and stair-core walls align across storeys.
  • Exterior walls terminate at the next level with zero top offset.
  • Wall faces and thicknesses match the cloud or survey model.
  • Required wall corners use the correct join condition.
  • Walls copied between levels were corrected to the destination cloud.
  • Stacked-wall component faces align and the intended segment is variable.
  • Full-height interior walls stop at the slab underside.
  • Partial-height walls retain their measured height.
  • Windows have the correct width, position, sill, height, interior direction, rows, columns, and panels.
  • Doors have the correct width, position, height, host, swing, opening direction, and configuration.
  • Roof perimeter edges, ridges, valleys, slopes, and special features match the reference geometry.
  • Roof thickness remains acceptable on steep, warped, or sub-element-edited faces.
  • Roof-hosted windows and openings still work when native hosting is required.
  • Curtain grids, end remainders, panels, mullions, and hosted families remain consistent after resizing.
10

Revit command reference

  • Close Inactive Views — close extra tabs while keeping one view for each open project.
  • Temporary Hide/Isolate — isolate source geometry; the blue view border shows it is active.
  • Reset Temporary Hide/Isolate — restore temporarily hidden geometry.
  • New Model → Browse — start from the approved project template.
  • Load RCS — connect to LumoCloud and load the point-cloud set.
  • Reference Plane — establish slab elevations and shared plan-alignment axes.
  • Wall Joins → Miter — control wall corner geometry.
  • Copy to Clipboard → Paste Aligned to Selected Levels — repeat continuous walls between storeys.
  • Attach Top/Base — terminate full-height interior walls at the slab above.
  • Massing & Site → In-Place Mass — hold imported SAT survey surfaces.
  • Architecture → Roof → Roof by Face — create a roof from mass faces.
  • Roof by Footprint — create a standard native roof from a boundary and slope definitions.
  • Model In-Place → Roofs → Sweep — create a path-and-profile-controlled roof form.
  • Model In-Place → Roofs → Revolve — create a rotational roof feature.
  • Modify Sub Elements — edit native roof ridges, edges, and points.
  • Split Lines — add ridges or surface breaks to a native roof.
  • Add Point — control local roof elevation.
  • Curtain Grid — add curtain-wall divisions.
  • Add/Remove Segments — control partial curtain-grid lines.
This guide retains the source's actionable Revit procedures, examples, caveats, and trade-offs. Project measurements shown as examples must always be replaced by values from the current point clouds and survey geometry.
